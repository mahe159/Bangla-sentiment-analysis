## Dataset (not included in this repository)
This project is designed for the **BanglaBook** dataset:

- Paper: "BanglaBook: A Large-scale Bangla Dataset for Sentiment Analysis from Book Reviews", Findings of ACL 2023.
- Source: https://github.com/mohsinulkabir14/BanglaBook (also on Hugging Face as Starscream-11813/BanglaBook)
- License: **Creative Commons Attribution-NonCommercial-ShareAlike 4.0 (CC BY-NC-SA 4.0)**

The dataset is not copied into this repository. Download it yourself and keep to its license.
A model trained on it may be affected by the NonCommercial and ShareAlike terms, so trained
model files are also not committed here. Use the results for learning and research, and check
the license before any commercial use.

## Code
The code in this repository was written for this project and is released under the MIT License
(see LICENSE). No code was copied from other repositories. The approach (TF-IDF features with a
linear classifier) is a standard baseline, and the BanglaBook paper reports its own baselines.
